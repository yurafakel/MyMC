# Как установить модпак друзьям

Для установки модпака друзьям не понадобятся Git или консоль. Всё необходимое можно скачать в виде готового архива через раздел **Releases** на странице репозитория.

## Этап 1. Перейдите в раздел релизов

Откройте страницу репозитория и найдите раздел **Releases** (обычно он находится в правой части страницы). Нажмите на него, чтобы открыть список доступных версий модпака.

## Этап 2. Выберите нужную версию

В списке релизов найдите нужную версию модпака и откройте её.

## Этап 3. Скачайте архив

Внизу страницы релиза найдите блок **Assets** и нажмите на **Source code (zip)**. Начнётся скачивание архива с файлами модпака.

## Этап 4. Распакуйте архив

После скачивания распакуйте ZIP-архив в удобное место на компьютере.

## Этап 5. Перенесите файлы в Minecraft

Откройте папку вашего игрового инстанса в лаунчере (Prism Launcher, Modrinth, MultiMC или стандартном лаунчере Minecraft).

Скопируйте из распакованного архива следующие папки:

- `mods` — моды;
- `config` — настройки модов;
- `scripts` — скрипты (если есть);
- `resourcepacks` — ресурспаки (если есть).

Перенесите их в папку игрового инстанса. Если система спросит о замене файлов, подтвердите её.

## Этап 6. Запустите игру

Запустите Minecraft, используя ту же версию игры и тот же загрузчик модов (**Fabric** или **NeoForge**), которые указаны в описании релиза.

**Готово!** После выполнения всех шагов модпак будет установлен и готов к запуску.
