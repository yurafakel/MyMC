# 🎮 MyMC — Сборки модов для игры

Удобное место для хранения, скачивания и отслеживания обновлений моих сборок модов Minecraft.

Каждая сборка изолирована и находится в своей отдельной ветке (`branch`), а свежие рабочие версии упакованы в **Releases** для быстрой загрузки в один клик.

---

## 📥 Как быстро скачать и запустить сборку

Друзьям не нужно разбираться с Git или консолью — всё скачивается готовым архивом через раздел релизов:

1. **Перейдите в раздел релизов:**
В правой колонке репозитория нажмите на **[suspicious link removed]** (или перейдите по вкладке).
2. **Выберите нужную сборку:**
Найдите нужную версию модпака в списке релизов.
3. **Скачайте архив:**
В блоке **Assets** нажмите на **Source code (zip)**.
4. **Установите в лаунчер:**
* Распакуйте скачанный zip-архив.
* Перенесите папки `mods`, `config` (и при наличии `scripts` / `resourcepacks`) в папку вашего инстанса Minecraft в лаунчере (Prism Launcher, Modrinth, MultiMC или стандартном).
* Запустите игру с указанной в релизе версией загрузчика (Fabric / NeoForge).
